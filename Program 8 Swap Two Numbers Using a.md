**Program 8: Swap Two Numbers Using a Third Variable**

**Algorithm**



Step 1: Start.

Step 2: Input two numbers a and b.

Step 3: Store the value of a in a temporary variable (temp).

Step 4: Assign the value of b to a.

Step 5: Assign the value of temp to b.

Step 6: Display the swapped values of a and b.

Step 7: Stop.



**Flowchart**



(START)

&#x20;  ↓

Input a, b

&#x20;  ↓

temp = a

&#x20;  ↓

a = b

&#x20;  ↓

b = temp

&#x20;  ↓

Display a, b

&#x20;  ↓

(STOP)
