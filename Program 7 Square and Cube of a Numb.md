**Program 7: Square and Cube of a Number**

**Algorithm**



Step 1: Start.

Step 2: Input a number (n).

Step 3: Calculate the square using the formula:

Square = n × n

Step 4: Calculate the cube using the formula:

Cube = n × n × n

Step 5: Display the square and cube.

Step 6: Stop.
